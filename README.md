# drikus-demo-deck — Public Issue Tracker

[**Drikus Demo Deck**](https://github.com/drikusroor/drikus-demo-deck) is a private project by [@drikusroor](https://github.com/drikusroor). It is a presentation / demo-deck application that lets you create, manage, and present slides and demos.

## About this repository

Because the main project lives in a private repository, this public repository exists as the place for anyone to:

- 🐛 **Report bugs** — something not working as expected? Open an issue!
- 💡 **Propose features** — have an idea that would make Drikus Demo Deck better? Share it here.
- 🙋 **Ask questions** — not sure how something works? Open a discussion or issue.
- 🔧 **Request improvements** — want an existing feature to work differently? Let us know.

## How to contribute

1. Click the [**Issues**](../../issues) tab above.
2. Click **New issue**.
3. Choose the appropriate template (bug report, feature request, etc.) or open a blank issue.
4. Describe your report or idea as clearly as possible so it can be understood and acted upon.

All feedback is welcome and appreciated!
